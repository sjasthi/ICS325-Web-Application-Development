CSS in 10 points

CSS is how every web page gets its colors, fonts, spacing, and layout. Read each point, then change the code in the dark box and watch the page on the right update instantly.

How to use this page: nothing you type here can break anything. Mess it up on purpose, then press Reset to get the original code back.

Give your own page some style

  1. Open the web page you built in earlier weeks in VS Code.
  2. Create a new file named style.css in the same folder.
  3. In the page's head, add <link rel="stylesheet" href="style.css">.
  4. Copy a few rules from these points into style.css, save, and refresh the browser.
  5. Right-click anything on the page, choose Inspect, and change CSS values live in the Styles panel.

Designers experiment constantly. Try ten colors before you pick one.
