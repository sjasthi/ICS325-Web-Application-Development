HTML in 10 points

HTML is how every web page is built. Read each point, then change the code in the dark box and watch the page on the right update instantly.

How to use this page: nothing you type here can break anything. Mess it up on purpose, then press Reset to get the original code back.

Make your own web page

  1. Open a plain text editor (Notepad, TextEdit in plain-text mode, or VS Code).
  2. Copy the code from Point 4, the page skeleton, and paste it in.
  3. Save the file as index.html.
  4. Double-click the file to open it in your browser.
  5. Change something, save, and refresh the browser. Repeat.

Breaking things and fixing them is how every web developer learns.

You can view the source of any web page by right-clicking and choosing "View page source."
