HTML forms in 10 points

Forms are how a website listens: sign-ups, searches, donations, even AI prompts. Read each point, change the code in the dark box, and fill in the form on the right.

How to use this page: nothing you type here can break anything, and no data leaves this page. When you submit a form, a green box shows what the browser would have sent. Press Reset to get the original code back.

Build a form for a real organization

  1. Pick a nonprofit or community group you care about, such as a food shelf, library, or animal shelter.
  2. In VS Code, create volunteer.html using the page skeleton from last week.
  3. Build a volunteer sign-up form with labels, at least three input types, a radio group, a <select>, and a <textarea>.
  4. Add validation: make the important fields required and use min, max, or pattern where they make sense.
  5. Open it in your browser and try to break it by submitting empty or silly answers.
  6. Use a structured prompt (role, task, context, format, constraints) to ask Claude to review your form for accessibility and missing labels.
