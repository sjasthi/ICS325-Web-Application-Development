Input, Change & Events

input reacts to edits as the user types. change fires when a value is committed; for text fields this commonly happens when focus leaves a changed field. event.target is the originating element; currentTarget is the element whose listener is running. Events often bubble through ancestors. preventDefault cancels a default action; it does not stop bubbling.

Native Validation

HTML provides required, type="email", minlength, min, and max constraints. The browser normally blocks invalid submissions before firing submit. checkValidity returns a Boolean; reportValidity also displays feedback. novalidate disables automatic submit validation, so this example explicitly calls reportValidity. Server validation is still necessary.

Custom Validation

Custom rules express requirements beyond basic HTML constraints. Number("") is 0, so check emptiness first. Reject non-finite values and require whole numbers when appropriate. setCustomValidity sets an error message; always clear old errors with an empty string before rechecking.
