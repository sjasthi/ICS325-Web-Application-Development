Variables & Types

Use const by default and let when reassignment is needed. Avoid older var in these exercises. JavaScript numbers include integers and decimals. Booleans are lowercase; null is an intentional empty value, while undefined often means no value has been assigned. A const array or object can still be modified.

Operators & Conditions

Prefer strict equality === and inequality !==. JavaScript == may convert types. Use &&, ||, and ! for logical operations. Python and JS both short-circuit logical expressions, which can return operand values; the example uses Boolean comparisons.

Arrays & Objects

An array resembles a Python list; an object stores named properties, similar to many dictionary uses. Both languages index from zero. JavaScript uses .length rather than len(). Object dot access is convenient for known property names.

Loops

Use for...of for array values. A counter loop has initialization, condition, and update. JavaScript has no built-in Python range() equivalent. A while loop needs a condition that eventually becomes false.

Functions & Practice

Parameters receive inputs; return sends a value to the caller. A function without an explicit return returns undefined. Variables declared inside a function are local; let and const also have block scope. Arrow functions are another syntax you will meet in event callbacks next week.
