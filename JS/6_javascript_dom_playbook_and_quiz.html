DOM & Loading

The DOM is the browser’s object representation of HTML. JavaScript can select, inspect, create, and change its nodes. This week focuses on page changes when you press Run; event listeners belong to Week 7. In a real page, defer waits until HTML is parsed before running an external script.

Selecting Elements

getElementById takes an ID without #. querySelector takes a CSS selector and returns the first match or null. querySelectorAll returns a static NodeList of matches; iterate with for...of or forEach. Check missing elements before using their properties.

Text & Values

Set textContent for plain text: it does not parse HTML and replaces existing child content. innerHTML parses markup; never use it to insert untrusted input. Inputs expose their current contents through value, not textContent. Checkbox state is checked.

Classes & Attributes

Prefer classList to apply reusable CSS rules; style sets inline CSS for individual properties. add, remove, and toggle change class membership. hidden controls visibility. Use setAttribute for HTML attributes and properties for current UI state. dataset reads data-* attributes as strings.

Create & Remove

createElement makes a detached element. Set its properties, then append it to a parent. remove detaches a node. Render array values as text instead of building untrusted HTML strings. Clear the list before rendering to avoid duplicate items.
